通过 OpenAI 兼容协议在 **Cherry Studio** 中自定义配置源力模型。

## 一、安装 Cherry Studio

访问 [Cherry Studio](https://www.cherry-ai.com/) 官网，下载并安装适合你操作系统的版本。

## 二、配置源力模型

在 Cherry Studio 中，打开「**设置 → 模型服务**」：

<Steps>
  <Step title="添加自定义供应商">
    点击模型服务列表下方的「**+ 添加服务商**」按钮，在「添加自定义提供商」弹窗中，把提供商名称填写为 Origin Power，然后点击「添加」保存。
  </Step>

  <Step title="配置 API 地址与密钥">
    在供应商配置页填写你的 `agw_` API 密钥（在[控制台](http://maas.dev.origin-power.com/zh-CN/dashboard)的「API 密钥」中创建）。API 地址只填根地址 `http://api.dev.origin-power.com`——Cherry Studio 会自动在地址后拼接 `/v1/chat/completions` 发起请求，**不要把 `/v1` 也填进去**。
  </Step>

  <Step title="添加模型">
    点击「**获取模型列表**」拉取当前可用的源力模型，在弹出的模型管理列表中把要用的模型（如 `glm-5.3`、`glm-5.3-flash`）加入列表。只有加入列表的模型才会出现在模型选择器中；也可以用每行的「+」手动输入模型 ID 添加。
  </Step>

  <Step title="启用并检测">
    打开供应商右上角的**启用开关**，然后点击「**检测**」并选择任一模型，验证连接是否成功。
  </Step>
</Steps>

| 配置项 | 填写内容 |
| :--- | :--- |
| 提供商名称 | Origin Power |
| API 地址 | `http://api.dev.origin-power.com`（自动拼接 `/v1/chat/completions`） |
| API 密钥 | 你的 `agw_` 源力 API 密钥 |
| 模型 ID | `glm-5.3`、`glm-5.3-flash` 等，见[模型概览](/models) |

<Tip>
  如果需要直接控制完整请求路径，可以在 API 地址栏填写完整地址并以 `#` 结尾（如 `http://api.dev.origin-power.com/v1/chat/completions#`）。以 `#` 结尾时 Cherry Studio 不再自动拼接版本路径，按你填写的地址原样请求。
</Tip>

## 三、开始使用

配置完成后，在对话中选择刚添加的源力模型即可开始使用。
