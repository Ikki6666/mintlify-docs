## 接入端点

源力支持多种协议接入，请根据你的工具选择适配的协议并配置正确的 Base URL：

| 协议类型 | Base URL |
| :--- | :--- |
| OpenAI Chat Completions 协议 | `http://api.dev.origin-power.com/v1` |
| OpenAI Responses 协议 | `http://api.dev.origin-power.com/v1` |

**核心步骤**

1. 根据工具支持的协议选择对应的 Base URL（仅在工具文档有特殊说明时按文档配置）。
2. 配置 API Key（`agw_` 开头，在[控制台](http://maas.dev.origin-power.com/zh-CN/dashboard)「API 密钥」中创建）。
3. 选择当前可用的源力AI平台模型 ID（见[模型概览](/models)）。

<Note>
  Claude Code 使用 Anthropic Messages 协议，接入前请确认所在环境已提供兼容的 `/v1/messages` 接口，详见 Claude Code 接入文档。
</Note>
