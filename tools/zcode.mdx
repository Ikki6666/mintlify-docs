[ZCode](https://zcode.z.ai/) 是一款面向 Long Horizon Task 的全功能 Agentic Development Environment（ADE），通过自研 ZCode Agent、多框架兼容、Bot 接入与移动端 Remote 控制，让 AI Agent 端到端稳定完成跨度长、步骤多的开发任务。本指南介绍如何在 ZCode 中使用源力AI平台模型。

## 一、安装 ZCode

访问 ZCode 官方[下载页面](https://zcode.z.ai/)，安装适合你操作系统的当前版本桌面应用。

## 二、配置源力AI平台模型

在模型供应商设置中，把源力添加为 OpenAI 兼容的自定义模型厂家：

<Steps>
  <Step title="打开模型设置">
    打开模型选择器，点击 Manage Models，再进入 Model Settings。
  </Step>

  <Step title="添加模型厂家">
    点击 Add Provider，创建 OpenAI 兼容的自定义模型厂家。
  </Step>

  <Step title="填写连接信息">
    模型厂家名称填写 Origin Power，填入下方 Base URL 和你的 `agw_` API 密钥。
  </Step>

  <Step title="保存并启用">
    等待 ZCode 拉取模型列表，然后启用需要使用的模型。
  </Step>
</Steps>

| 配置项 | 填写内容 |
| --- | --- |
| 模型厂家名称 | Origin Power |
| 协议 | OpenAI compatible |
| Base URL | `http://api.dev.origin-power.com/v1` |
| API Key | 你的 `agw_` 源力 API 密钥 |

<Tip>
  手动配置时，请确认 Base URL 精确到 `/v1`：`http://api.dev.origin-power.com/v1`，ZCode 会从该地址拉取当前可用的模型列表。
</Tip>

## 三、保存并切换模型

配置完成后，保存设置，即可在 ZCode 的模型切换菜单中选择 Origin Power 分组下刚配置好的模型。

<Check>
  如果列表中没有目标模型，重新打开 Model Settings，并确认该模型已经启用。
</Check>

## 四、验证连接

<Steps>
  <Step title="打开小型测试项目">
    第一次验证使用可丢弃项目或干净仓库，避免请求修改重要代码。
  </Step>

  <Step title="发送只读指令">
    让 ZCode 只总结仓库，不要编辑文件。
  </Step>

  <Step title="核对用量">
    在源力控制台的用量页面确认请求、模型、Token 数和费用。
  </Step>
</Steps>

## 五、常见问题

<AccordionGroup>
  <Accordion title="模型列表为空">
    * 确认 Base URL 包含 `/v1`，并确认 API 密钥有效。
    * 点击刷新模型厂家模型列表后重试。
  </Accordion>

  <Accordion title="401 或 403 鉴权失败">
    * 更换 API 密钥，并确认复制内容没有首尾空格。
    * 密钥被轮换或删除后，更新 Model Settings 中的凭证。
  </Accordion>

  <Accordion title="找不到模型">
    * 刷新模型厂家模型列表，并选择已启用的源力AI平台模型。
    * 当前可用的模型 ID 见[模型概览](/models)。
  </Accordion>

  <Accordion title="请求参数被拒绝">
    换用支持 ZCode 所请求能力的模型，例如工具调用或图像输入。
  </Accordion>
</AccordionGroup>
