除编程工具外，以下通用 Agent 工具也可接入源力AI平台模型：

<CardGroup cols={2}>
  <Card title="OpenClaw" icon="boxes" href="/tools/openclaw">
    可在本地设备运行的开源 AI 助手，支持多平台使用，并可通过 Skills 扩展能力。
  </Card>

  <Card title="Cherry Studio" icon="window" href="/tools/cherry-studio">
    AI 应用程序集成开发环境，支持多种模型接入。
  </Card>

  <Card title="Hermes Agent" icon="shield" href="/tools/hermes-agent">
    开源自进化 AI 智能体，持久记忆越用越聪明。
  </Card>
</CardGroup>

<Tip>
  任何支持 OpenAI 兼容接口的 Agent 工具，都可以通过 Base URL `http://api.dev.origin-power.com/v1` 与 `agw_` API 密钥接入源力AI平台模型，模型 ID 请使用[模型概览](/models)中的真实 ID。
</Tip>
