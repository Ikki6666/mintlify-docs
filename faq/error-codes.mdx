title: "错误码"
description: "源力 API 常见 HTTP 状态码与处理建议。"
---

调用 API 出错时，服务器会返回 HTTP 状态码和错误信息。请基于状态码分类处理，不要根据错误消息里的自然语言分支。

## 状态码说明

| 状态码 | 分类 | 说明与建议动作 |
| :--- | :--- | :--- |
| 400 / 422 | 非法请求 | 请求体不合法，或使用了模型不支持的参数。校验请求体与模型支持参数，不要原样重试。 |
| 401 | 鉴权失败 | API Key 无效或未正确传入。确认服务端使用的是预期且有效的密钥（`agw_` 开头），排查时不要暴露密钥。 |
| 402 | 账户状态 | 钱包或额度不足。通过控制台检查钱包余额或额度，并通知运营人员。 |
| 404 | 路由或模型 | 请求路径错误，或 model ID 不存在。通过 `GET /v1/models` 核对模型 ID，并检查请求路径。 |
| 408 / 429 / 5xx | 临时失败 | 临时性失败。使用小预算的指数退避重试，超过重试预算后返回可控的失败。 |

<Warning title="不要原样重试非法请求">
  `400` / `422` 属于请求本身的问题，原样重试不会成功，应先修正请求体或参数；重试策略只适用于 `408` / `429` / `5xx` 等临时性失败。
</Warning>

## 反馈问题时附上排查上下文

需要提交工单或反馈问题时，请附上以下信息，能显著加快定位：

* 移除敏感值后的 HTTP 状态码和响应体。
* 准确的 model ID 和不含密钥的请求配置。
* 时间、请求 ID 和网关返回时的 trace ID。
* 是否尝试过重试或兜底，以及对应结果。

接口级的完整说明见 API 文档中的[错误处理](/api-reference/errors)。
