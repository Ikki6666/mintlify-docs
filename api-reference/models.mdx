---
title: "列出模型"
description: "发现当前调用账户可使用的准确 model ID。"
---

**GET** `/v1/models`

返回当前鉴权密钥可访问的模型 ID。

在新环境中固定 model ID 前先调用此端点。控制台「模型」目录还提供能力说明和当前价格。

```bash
curl http://api.dev.origin-power.com/v1/models \
  -H "Authorization: Bearer $ORIGIN_POWER_API_KEY"
```

## 响应

```json
{
  "object": "list",
  "data": [
    { "id": "glm-5.2", "object": "model", "owned_by": "z-ai" },
    { "id": "deepseek-v4-flash", "object": "model", "owned_by": "deepseek" },
    { "id": "gpt-5.6-luna", "object": "model", "owned_by": "openai" }
  ]
}
```

<Warning title="不要从显示名推测 ID">
  在 completion 请求中原样使用 `data[].id`。模型厂家前缀和版本标点都属于 ID。
</Warning>
