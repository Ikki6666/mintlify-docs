**GET** `/v1/models`

返回当前鉴权密钥可访问的模型 ID。

在新环境中固定 model ID 前先调用此端点。控制台「模型」目录还提供能力说明和当前价格。

<RequestExample>

```bash cURL
curl http://api.dev.origin-power.com/v1/models \
  -H "Authorization: Bearer $ORIGIN_POWER_API_KEY"
```

</RequestExample>

<Warning title="不要从显示名推测 ID">
  在 completion 请求中原样使用 `data[].id`。模型厂家前缀和版本标点都属于 ID。
</Warning>
