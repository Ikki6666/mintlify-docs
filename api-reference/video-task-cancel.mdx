**DELETE** `/api/v3/videos/{task_id}`

取消自己 API Key 提交的视频生成任务。行为按任务状态区分：仅 **排队中（`queued`）** 的任务可取消，取消**不计费**（预扣额度自动退回）；**生成中（`processing`）的任务不可取消**，会正常完成并按正常计费（与 MiniMax 官方一致）。音乐任务的取消见[取消音乐任务](/api-reference/music-task-cancel)。

<RequestExample>

```bash cURL
curl -X DELETE http://api.dev.origin-power.com/api/v3/videos/video_xxx \
  -H "Authorization: Bearer $ORIGIN_POWER_API_KEY"
```

</RequestExample>

<ResponseExample>

```json 取消成功（排队中）
{ "data": { "task_id": "video_5f3ae21", "action": "cancelled", "status": "cancelled" } }
```

</ResponseExample>

## 各状态的取消行为

| 任务状态 | HTTP | 响应 | 计费 |
| :--- | :--- | :--- | :--- |
| `queued`（排队中） | 200 | `{"data":{"task_id":"...","action":"cancelled","status":"cancelled"}}` | 不计费（预扣自动退回） |
| `processing`（生成中） | 409 | `Conflict`：`task is in working state and cannot be cancelled; it will complete normally and be billed` | 正常生成、正常计费 |
| `completed` / `failed` / `timeout`（终态） | 409 | `Conflict`：`task already finished and cannot be cancelled` | — |
| 任务不存在 / 非本人 Key | 404 | `NotFound`：`task not found` | — |
| `task_id` 格式非法 | 400 | `BadRequest`：`invalid task_id: expected video_ prefix with 24 hex characters` | — |

## 取消规则

* 只能取消自己 API Key 提交的任务（按 Key 指纹校验归属，非本人返回 404，不泄露任务存在性）
* 排队中的任务取消后，[查询视频任务](/api-reference/video-task-query)返回 `failed` 终态，`error` 提示 `cancelled by user ... (queued, no charge)`
* 查询参数（如 `?dry_run=1`）会被忽略
* 任务记录不因取消而删除，取消后仍可查询

<Note title="失败不计费">
  排队中被取消的任务不计费；其他原因 `failed` 的任务同样不计费，预扣额度自动退回，修正参数后重新提交即可。
</Note>

错误码与排查见[错误码](/faq/error-codes)。
