---
title: "错误"
description: "利用 HTTP 状态、返回的请求上下文和有上限的恢复策略处理失败。"
---

不要根据错误消息里的自然语言分支。保存 HTTP 状态、model ID、时间和请求 ID，再决定修正、等待还是升级处理。

## 状态码说明

| 状态 | 分类 | 动作 |
| --- | --- | --- |
| 400 / 422 | 非法请求 | 校验请求体和模型支持的参数；不要原样重试。 |
| 401 | 鉴权 | 确认服务端使用的是预期且有效的密钥；排查时不要暴露密钥。 |
| 402 | 账户状态 | 通过控制台检查钱包或额度，并通知运营人员。 |
| 404 | 路由或模型 | 通过 `/v1/models` 核对 model ID，并检查请求路径。 |
| 408 / 429 / 5xx | 临时失败 | 使用很小的指数退避重试预算，之后返回可控的失败。 |

## 支持排查所需的上下文

- 移除敏感值后的 HTTP 状态和响应体。
- 准确的 model ID 和不含密钥的请求配置。
- 时间、请求 ID 和网关返回时的 trace ID。
- 是否尝试重试或兜底，以及对应结果。
