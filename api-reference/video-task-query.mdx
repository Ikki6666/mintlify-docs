**GET** `/api/v3/videos/{task_id}`

查询由[创建视频任务](/api-reference/video-task-create)返回的任务 ID 对应的状态。任务未完成时返回当前状态，完成后返回视频下载链接。

轮询间隔建议 **≥ 5 秒**；查询接口轻量，但请勿高频轰炸。

<RequestExample>

```bash cURL
curl http://api.dev.origin-power.com/api/v3/videos/video_task_xxx \
  -H "Authorization: Bearer $ORIGIN_POWER_API_KEY"
```

</RequestExample>

<ResponseExample>

```json 成功
{
  "code": 0,
  "data": {
    "task_id": "video_5f3ae21",
    "status": "completed",
    "progress": null,
    "video_url": "http://minio.example/out.mp4?X-Amz-..."
  },
  "message": "成功"
}
```

```json 失败
{
  "code": 0,
  "data": {
    "task_id": "video_5f3ae21",
    "status": "failed",
    "progress": null,
    "error": "具体原因"
  },
  "message": "成功"
}
```

</ResponseExample>

## 任务状态

| status | 含义 |
| :--- | :--- |
| `queued` | 已提交，排队 / 网关在途 |
| `processing` | 生成中 |
| `completed` | 成功，`video_url` 可用 |
| `failed` | 失败，`error` 带原因 |
| `timeout` | 超时兜底（生成超 1 小时） |

排队中的任务被本人取消后，查询返回 `failed` 终态（`error` 含 `cancelled by user`，任务不计费），见[取消视频任务](/api-reference/video-task-cancel)。

## 任务不存在（404）

查询不存在、已过期或格式错误的 `task_id` 时返回 **HTTP 404**，响应体为 `{"code":10004,"data":null,"message":"任务不存在"}`。

## 下载规则

* `video_url` 是对象存储**预签名直链，1 小时有效**。过期后重新查询本接口即可获得新链接，无需重新生成。
* 下载直连对象存储，**不经过网关、不消耗配额**。
* 任务记录保留 7 天（管理台可见），产物长期存储。
* 只能查询自己 API Key 提交的任务。

<Note title="失败不计费">
  `failed` 任务不计费，预扣额度自动退回。查看 `error` 中的原因，修正参数后重新提交即可，不要原样重试。
</Note>
