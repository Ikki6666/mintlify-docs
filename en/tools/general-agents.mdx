Beyond coding tools, the following general Agent tools can also connect to Origin Power models:

<CardGroup cols={2}>
  <Card title="OpenClaw" icon="boxes" href="/en/tools/openclaw">
    An open-source AI assistant that runs on local devices, works across platforms, and extends its capabilities through Skills.
  </Card>

  <Card title="Cherry Studio" icon="window" href="/en/tools/cherry-studio">
    An AI application development environment with multi-model support.
  </Card>

  <Card title="Hermes Agent" icon="shield" href="/en/tools/hermes-agent">
    An open-source, self-evolving AI agent with persistent memory that gets smarter over time.
  </Card>
</CardGroup>

<Tip>
  Any Agent tool with an OpenAI-compatible interface can connect to Origin Power models via the Base URL `http://api.dev.origin-power.com/v1` and an `agw_` API key. Always use real model IDs from [Model overview](/en/models).
</Tip>
