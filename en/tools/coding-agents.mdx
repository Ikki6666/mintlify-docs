## Endpoints

Origin Power supports several protocols. Pick the one that matches your tool and configure the correct Base URL:

| Protocol type | Base URL |
| :--- | :--- |
| OpenAI Chat Completions protocol | `http://api.dev.origin-power.com/v1` |
| OpenAI Responses protocol | `http://api.dev.origin-power.com/v1` |

**Core steps**

1. Choose the Base URL that matches your tool's protocol (unless the tool's setup guide says otherwise).
2. Configure the API key (`agw_` prefix, created in the console under **API keys**).
3. Select a current Origin Power model ID (see [Model overview](/en/models)).

<Note>
  Claude Code uses the Anthropic Messages protocol. Confirm your environment exposes a compatible `/v1/messages` endpoint before connecting — see the Claude Code setup guide for details.
</Note>
