平台提供 ComfyUI 自定义节点（`origin-gateway` 分类），让你在 ComfyUI 工作流中直接使用平台视频生成能力，无需手写轮询代码。

## 工作流结构

节点包内置一套预连线工作流，由三个节点组成：

1. **提交视频任务** — 参数与[视频生成指南](/multimodal/video-generation)中的接口参数完全一致：提示词、时长、比例、清晰度步数，图生视频同样通过该节点传入首帧。
2. **等待并下载** — 自动轮询任务状态，完成后把成片写入你本地的文件。
3. **显示文本** — 展示状态与结果信息，便于在工作流中检查产出。

产物自动落入 ComfyUI 输出目录，可以直接接入后续的加工或导出节点。

## 获取方式

自定义节点通过平台公告发布，或联系网关团队获取安装包。安装后按预连线工作流填写提示词即可出片。

<Note>
  ComfyUI 中提交的任务走同一套视频接口，同样受单个 API Key 在途任务 ≤ 2 的并发限制；批量出片时建议串行提交。
</Note>
